# Starter page

## Development

### Frontend

```
npm install
npm run dev
```

### Backend

```bash
docker compose up -d --build
```

### Addresses

Frontend will be running at:
- http://localhost:5173

Backend will be running at:
- API: http://127.0.0.1:8090/api
- Admin dashboard: http://127.0.0.1:8090/_
